# Source Provenance and Attribution

XCloud5 is a separately maintained PlayStation 4 homebrew project. It combines pre-existing GPL-licensed work and later modifications made during XCloud5 development. The existence of an earlier contribution **does not mean that its author created or maintains all of XCloud5**.

## Earlier XCloud4 source

Some parts of XCloud5 were derived from the independent [XCloud4 project](https://github.com/asp11edgr/XCloud4), which includes commits authored by [asp11edgr](https://github.com/asp11edgr). The original code and subsequent work may be interleaved across the source tree; the historical Git commits are the authoritative record of those changes. It would be inaccurate to claim that asp11edgr authored the entire current XCloud5 project or its newer branding.

## Subsequent XCloud5 changes

Later development introduced Xbox Home-style UI and navigation, animations, catalog and artwork changes, Microsoft sign-in timeout adjustments, build scripts, packaging improvements, the XCloud5 identity, documentation, and launcher artwork.

Individual historical Git commits may credit [codex](https://github.com/codex) where that GitHub identity was recorded as their author (for example, commit `393fbcc6`), as well as the repository owner and other historical identities. Those commits represent **specific contributions**, not authorship or ownership of all current code.
